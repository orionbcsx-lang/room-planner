# Room Planner

Plan a room in the browser: draw its shape (straight or curved walls, wall
heights, windows and doors), then place furniture and see it in 2D and 3D.

**Open it:** the GitHub Pages address of this repository.

- Built-in furniture works on its own.
- Pasting a furniture shop's product link (to add the real product, sized from
  its page) needs the companion browser extension, "Room Planner Grabber",
  loaded in Edge or Chrome.

Everything you draw is kept in your own browser (and in files you save with
**Save file**); nothing is sent to a server.
